接口开发文档

手把手教你创建带计费功能的 API 接口，小白也能看懂

快速上手：5分钟创建一个带计费的接口

本系统支持 3 种计费模式：免费公开 / 会员专用 / 按次计费。你只需写一行验证代码，系统自动处理鉴权、扣费、限流等所有逻辑。

1 认识三种计费类型

在「添加接口」或「管理接口」页面，你会看到 3 种计费类型。它们的区别如下：

计费类型调用要求是否扣费适用场景
免费公开 无需 API Key，任何人可调用 免费 公开演示接口、公共服务
会员专用 需要 API Key + 会员等级≥1 免费（需会员身份） 会员专属高级接口
按次计费 需要 API Key，普通用户扣余额 每次扣 ¥价格（会员免费） 付费商业接口、消耗资源接口
💡 小提示：计费类型可以在「管理接口」列表中随时切换，立即生效。比如把"按次计费"改成"免费公开"，下一秒用户调用就不需要 API Key 了。
2 创建接口文件

在服务器的 /API/ 目录下创建一个 PHP 文件，比如 weather.php。

只需 3 步：引入验证 → 写逻辑 → 输出 JSON。验证代码必须在最顶部。

<?php
// ① 引入 API Key 验证中间件（必须在最顶部）
require_once __DIR__ . '/../Core/api_key_auth.php';

// ② 你的业务逻辑代码
$city = $_GET['city'] ?? '北京';
$weather = '晴天，25°C';

// ③ 输出 JSON 结果
header('Content-Type: application/json; charset=utf-8');
echo json_encode([
    'code' => 0,
    'msg'  => 'success',
    'data' => [
        'city'    => $city,
        'weather' => $weather
    ]
], JSON_UNESCAPED_UNICODE);

包含调用统计、获取用户信息、错误处理等完整功能。

<?php
/**
 * 天气查询接口 - 完整版
 * 计费类型由后台数据库配置决定
 */

// ① 引入验证中间件（必须在最顶部）
require_once __DIR__ . '/../Core/api_key_auth.php';
require_once __DIR__ . '/function.php';

// ② 获取当前调用用户信息
$user = $GLOBALS['api_auth'];

// ③ 业务逻辑
$city = $_GET['city'] ?? '北京';
if (empty($city)) {
    header('Content-Type: application/json; charset=utf-8');
    echo json_encode(['code' => -1, 'msg' => '缺少城市参数']);
    exit;
}

$result = getWeather($city);

// ④ 输出结果
header('Content-Type: application/json; charset=utf-8');
echo json_encode([
    'code' => 0,
    'msg'  => 'success',
    'data' => [
        'city'        => $city,
        'weather'     => $result['weather'],
        'temperature' => $result['temp']
    ],
    'user' => [
        'username'    => $user['username'],
        'level'       => $user['level_name'],
        'calls_today' => $user['calls_today'],
        'daily_limit' => $user['daily_limit']
    ]
], JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);

如果你的接口在后台设置为「免费公开」，即使不写验证代码也能访问。但强烈建议依然写上验证代码，这样可以自动统计调用次数、将来切换计费类型不用改代码。

<?php
// 免费公开接口示例
// 即使后台设为"免费公开"，这行代码也建议保留：
// - 会自动统计调用次数
// - 将来想改成"会员专用"或"按次计费"，无需修改代码
require_once __DIR__ . '/../Core/api_key_auth.php';

$data = [
    'ip'   => $_SERVER['REMOTE_ADDR'],
    'time' => time()
];

header('Content-Type: application/json; charset=utf-8');
echo json_encode([
    'code' => 0,
    'msg'  => 'success',
    'data' => $data
], JSON_UNESCAPED_UNICODE);
💡 为什么建议保留验证代码？因为验证中间件会自动判断当前接口的计费类型：如果是"免费公开"就跳过验证；如果是"会员专用"或"按次计费"就检查 API Key。你写一次代码，三种模式通用。
3 在后台添加接口记录

创建好 PHP 文件后，还需要在后台「添加接口」页面登记，系统才能识别和管理它。

1

填写接口名称和英文名

英文名必须和 PHP 文件名一致（不带 .php）。比如你创建了 weather.php，英文名就填 weather。

2

选择计费类型

根据需求选择：免费公开 / 会员专用 / 按次计费。如果选"按次计费"，还需要填写单次调用价格。

3

填写接口说明和参数

按格式填写请求参数、返回参数、错误码说明，方便用户查阅文档。

4

保存即可

保存后接口立即生效，用户就可以通过 /API/weather.php 调用了。

4 用户如何调用接口

对于「会员专用」和「按次计费」的接口，用户调用时需要提供 API Key。有两种传递方式：

方式一：GET 参数（最简单）
# 直接在 URL 后加 ?apikey=你的密钥
https://你的域名/API/weather.php?city=北京&apikey=sk_xxxxxxxxxxxxx
方式二：Header 头（更安全，推荐）
# cURL 示例
curl -X GET "https://你的域名/API/weather.php?city=北京" \
     -H "X-API-Key: sk_xxxxxxxxxxxxx"

# PHP 示例
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://你的域名/API/weather.php?city=北京");
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "X-API-Key: sk_xxxxxxxxxxxxx"
]);
$response = curl_exec($ch);
JavaScript 调用示例
fetch('https://你的域名/API/weather.php?city=北京', {
    headers: {
        'X-API-Key': 'sk_xxxxxxxxxxxxx'
    }
})
.then(res => res.json())
.then(data => console.log(data));
免费公开接口不需要传 API Key，直接访问 /API/weather.php 即可。

6 完整实战：创建"每日一言"接口

下面演示从创建文件到后台登记的完整流程，计费类型设为「会员专用」。

1. 创建文件 /API/yiyan.php
<?php
// 引入验证中间件（自动支持三种计费模式）
require_once __DIR__ . '/../Core/api_key_auth.php';

// 一言数据
$sentences = [
    '人生如逆旅，我亦是行人。',
    '千里之行，始于足下。',
    '不积跬步，无以至千里。',
    '长风破浪会有时，直挂云帆济沧海。'
];
$yiyan = $sentences[array_rand($sentences)];

// 获取调用者信息
$user = $GLOBALS['api_auth'] ?? [];

// 输出结果
header('Content-Type: application/json; charset=utf-8');
echo json_encode([
    'code' => 0,
    'msg'  => 'success',
    'data' => [
        'yiyan' => $yiyan,
        'from'  => '古诗词'
    ],
    'caller' => $user['username'] ?? '游客'
], JSON_UNESCAPED_UNICODE);
2. 在后台「添加接口」登记
字段填写内容
接口名称每日一言
英文名yiyan
接口地址（自动生成）/API/yiyan.php
计费类型 会员专用
接口说明随机返回一句古诗词，陶冶情操
请求参数无
返回参数yiyan:一言内容 / from:出处
3. 调用测试
# 会员用户调用（带 API Key）
curl "https://你的域名/API/yiyan.php" \
     -H "X-API-Key: sk_xxxxxx"

# 返回结果
{
    "code": 0,
    "msg": "success",
    "data": {
        "yiyan": "长风破浪会有时，直挂云帆济沧海。",
        "from": "古诗词"
    },
    "caller": "张三"
}
💡 想改成免费接口？不用改代码！去「管理接口」列表，把计费类型下拉框选成「免费公开」即可，立即生效。
? 常见问题
Q：为什么我的接口提示"缺少 API Key"？
A：说明这个接口在后台设置了「会员专用」或「按次计费」，调用时需要传 API Key。两种传参方式：
① URL 参数：?apikey=sk_xxx
② Header 头：X-API-Key: sk_xxx
如果想让所有人免费调用，去「管理接口」把计费类型改成「免费公开」。
Q：我在后台改了计费类型，为什么不生效？
A：请检查接口文件（/API/xxx.php）顶部是否有这行代码：
require_once __DIR__ . '/../Core/api_key_auth.php';
如果没有引入验证中间件，后台的计费配置就不会起作用。所有接口文件都必须引入这行代码。
Q：免费公开接口还需要写验证代码吗？
A：强烈建议写。虽然不写也能访问，但写了有两个好处：
① 自动统计调用次数，后台能看到数据
② 将来想改成收费/会员专用，无需修改代码，后台切换即可
Q：按次计费接口，会员用户也要扣费吗？
A：不需要。按次计费接口的规则是：普通用户扣余额，会员免费调用。系统会自动判断用户身份，会员等级≥1 的用户调用不扣费。
Q：用户在哪里获取 API Key？
A：用户在前台注册登录后，进入「用户中心 → API Key 管理」页面生成密钥。密钥格式为 sk_ 开头的字符串。管理员可以在后台「会员管理」查看所有用户的密钥。
Q：用户每日调用次数限制是多少？
A：根据会员等级自动限制，在「后台 → 套餐管理」中配置：
• 普通用户（等级0）：默认 0 次（需升级会员）
• 月度会员（等级1）：1000 次/天
• 年度会员（等级2）：10000 次/天
免费公开接口不受此限制。
