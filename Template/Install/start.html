安装前准备

欢迎使用 MXGAPI 管理系统！在开始安装之前，请确保您已准备好以下信息。

整个安装过程大约需要 5 分钟，请确保您的服务器环境符合要求。
  • MySQL 数据库信息（地址、端口、库名、用户名、密码）
  • PHP 版本 >= 7.4，且已启用 cURL、MySQLi、Mbstring 扩展
  • 网站根目录需具备 写入 权限
  • 管理员邮箱（用于接收系统通知和密码找回）
